# WS16 — Disputes Implementation Plan


**Goal:** A buyer can challenge a run's charge within 14 days. The developer adds their side, a Karya admin decides, and any refund goes back to the buyer's wallet. Decided disputes appear on the agent's public track record without naming the buyer.

**Architecture:** One `DisputeService` owns the lifecycle `OPEN → AWAITING_DECISION → REFUNDED | NOT_REFUNDED` (or `WITHDRAWN`), always under a row lock on the dispute. A refund writes a `REVERSAL` ledger entry tied to the dispute and credits the buyer wallet under its row lock. Because it is a `REVERSAL`, WS15's month-to-date spend nets it out automatically. The developer's side of the money is recorded as `amount_held` on the dispute. The double-entry ledger and payouts arrive in WS10, and WS10's earnings screen reads `DisputeService.heldForDeveloper` instead of this plan inventing developer accounts early. A small ShedLock job moves disputes to `AWAITING_DECISION` when the developer's reply window closes. Lifecycle changes publish domain events (WS15 outbox), so they appear in the activity feed.

**Tech Stack:** Java 21, Spring Boot 3.3.4, Postgres 16 + Flyway, ShedLock 5.16.0, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-09-23-agent-store-developer-platform-and-sandbox-design.md` §5 **WS16** (read it first), §10 rows 11 and 16, and the refund rule in §10.1.

**Prerequisites:** WS0 (run lifecycle, `ExecutionFixtures`, `SchedulingConfig`), WS13 (`IdentityFixtures`, `MeController.currentClaims()`), WS15 (`DomainEventPublisher`, `DomainEventType`, `ApiProblemException`, `LedgerEntryRepository.netChargedSince`).

## Global Constraints

- Flyway: WS0 `V12`–`V16`, WS13 `V17`–`V21`, WS15 `V22`–`V25`, WS14 `V26`–`V29`. **This plan uses `V30`–`V31`.** Renumber if another plan merges first.
- A run can be disputed when **all** of these hold:
  - it is terminal and `total_charged > 0`;
  - `completed_at` is within `agentstore.disputes.window` (default `P14D`);
  - the caller is a `BUYER_ADMIN` of the run's buyer org;
  - the run has never been disputed before (one dispute per run, ever).
- `amount_disputed = amount_held = run.total_charged` when the dispute opens.
- `respond_by = opened + 7 days`, `decide_by = opened + 14 days`.
- An admin can decide only once the dispute is `AWAITING_DECISION`, which means the developer has replied or `respond_by` has passed (409 otherwise).
- `0 < amount_refunded ≤ amount_disputed` for `REFUNDED`. `public_summary` is required on every decision (1–280 characters), written by the admin.
- Refunds come **only** from the developer's share. The platform keeps its fee (spec §10.1). In this plan that means: the buyer wallet is credited, a `REVERSAL` ledger entry records it, and `amount_held` is released. WS10 posts the developer-payable leg.
- The public view never shows the buyer's name or their own words, only `public_summary`, outcome, amount refunded and the decision date. The developer sees the buyer org name (it is their counterparty); other developers never do.
- Errors use WS15's `ApiProblemException`:
  - `DISPUTE_WINDOW_CLOSED` (409)
  - `ALREADY_DISPUTED` (409)
  - `NOT_DISPUTABLE` (409)
  - `WAITING_FOR_DEVELOPER` (409)
  - `ALREADY_DECIDED` (409)
  - `REFUND_OUT_OF_RANGE` (400)
- Money is `BigDecimal` scale 2.
- **Deferred, with the reason:** developer payable and hold postings (WS10 ledger redesign), dispute emails (add categories to WS14 when the dispute screens are built), and `medianReplyHours` on the publisher card (WS7 reads `dispute_message`).

## Review Focus

1. **Two refund decisions submitted at the same moment for one dispute** (two admins, or a double click) must credit the wallet once. [Task 2]
2. **A refund larger than the disputed amount, zero, or negative** must be refused, so a typo cannot pay out more than was charged. [Task 2]
3. **A buyer disputing a run that charged nothing** (rejected at the gate, failed before charging) must be refused. There is nothing to refund and nothing to hold. [Task 1]
4. **The public track record** must never include the buyer org's name, even when the admin's summary is empty. Deciding without a summary is refused. [Tasks 2–3]
5. **A refund in the current month** must lower that month's spend used by WS15's monthly-limit check, so the buyer isn't blocked by money they got back. [Task 2]

```java
    public record ChargedRun(ExecutionFixtures.Scenario scenario, Run run, OrgMembership buyerAdmin,
                             OrgMembership developer) {}

    private final ExecutionFixtures fixtures;
    private final IdentityFixtures identity;
    private final RunRepository runRepository;
    private final UsageEventRepository usageEventRepository;
    private final LedgerService ledgerService;

    public DisputeFixtures(ExecutionFixtures fixtures, IdentityFixtures identity, RunRepository runRepository,
                           UsageEventRepository usageEventRepository, LedgerService ledgerService) {

        this.identity = identity;
        this.runRepository = runRepository;
        this.usageEventRepository = usageEventRepository;
        this.ledgerService = ledgerService;
    }

    public ChargedRun chargedRun(String amount) {
        var s = fixtures.liveTierA(new BigDecimal("500.00"), new BigDecimal("10000.00"));
        Run run = fixtures.run(s, RunStatus.COMPLETED, "fake-sandbox-" + UUID.randomUUID(), "tok-" + UUID.randomUUID());
        if (new BigDecimal(amount).signum() > 0) {
            UsageEvent event = usageEventRepository.save(new UsageEvent(null, run.getId(), s.buyer().getId(),
                    BigDecimal.ONE, new BigDecimal(amount), new BigDecimal(amount)));
            ledgerService.chargeUsageEvent(event.getId());
        }
        run.setTotalCharged(new BigDecimal(amount));
        run.setCompletedAt(Instant.now());
        run = runRepository.save(run);
        OrgMembership buyerAdmin = identity.member(s.buyer(), "buyer-" + UUID.randomUUID() + "@acme.example",
                UserRole.BUYER_ADMIN, null);
        OrgMembership developer = identity.member(s.version().getAgent().getDeveloperOrg(),
                "dev-" + UUID.randomUUID() + "@ledgerline.example", UserRole.DEVELOPER, null);
        return new ChargedRun(s, run, buyerAdmin, developer);
    }
}
```

```java
package com.agentstore.platform.disputes;

import com.agentstore.platform.AbstractIntegrationTest;
import com.agentstore.platform.execution.Run;
import com.agentstore.platform.execution.RunRepository;
import com.agentstore.platform.identity.IdentityFixtures;
import com.agentstore.platform.identity.OrgMembership;
import com.agentstore.platform.identity.UserRole;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.web.client.TestRestTemplate;
import org.springframework.boot.test.web.server.LocalServerPort;
import org.springframework.http.*;

import java.time.Duration;
import java.time.Instant;
import java.util.Map;
import java.util.UUID;

import static org.assertj.core.api.Assertions.assertThat;

class OpenDisputeTest extends AbstractIntegrationTest {

    @LocalServerPort
    int port;
    @Autowired
    TestRestTemplate rest;
    @Autowired
    DisputeFixtures disputes;
    @Autowired
    IdentityFixtures identity;
    @Autowired
    RunRepository runRepository;
    @Autowired
    DisputeService disputeService;

    String url(String path) {
        return "http://localhost:" + port + path;
    }

    HttpHeaders bearer(OrgMembership m) {
        HttpHeaders headers = new HttpHeaders();
        headers.setBearerAuth(identity.tokenFor(m));
        headers.setContentType(MediaType.APPLICATION_JSON);
        return headers;
    }

    ResponseEntity<Map> open(DisputeFixtures.ChargedRun c, OrgMembership who) {
        return rest.exchange(url("/api/v1/runs/" + c.run().getId() + "/disputes"), HttpMethod.POST,
                new HttpEntity<>(Map.of("reason", "WRONG_OUTPUT", "details", "6 matches were against the wrong invoice"),
                        bearer(who)), Map.class);
    }

    @Test
    void aBuyerAdminOpensADisputeAndTheWholeChargeIsHeld() {
        var c = disputes.chargedRun("284.00");

        var response = open(c, c.buyerAdmin());

        assertThat(response.getStatusCode()).isEqualTo(HttpStatus.CREATED);
        assertThat(response.getBody().get("status")).isEqualTo("OPEN");
        assertThat(response.getBody().get("amountHeld")).isEqualTo(284.0);
        Instant created = Instant.parse((String) response.getBody().get("createdAt"));
        assertThat(Duration.between(created, Instant.parse((String) response.getBody().get("respondBy"))))
                .isEqualTo(Duration.ofDays(7));
        UUID devOrg = c.developer().getOrg().getId();
        assertThat(disputeService.heldForDeveloper(devOrg)).isEqualByComparingTo("284.00");
    }

    @Test
    void aRunCanBeDisputedOnlyOnce() {
        var c = disputes.chargedRun("284.00");
        open(c, c.buyerAdmin());

        var second = open(c, c.buyerAdmin());

        assertThat(second.getStatusCode()).isEqualTo(HttpStatus.CONFLICT);
        assertThat(second.getBody().get("code")).isEqualTo("ALREADY_DISPUTED");
    }

    @Test
    void aRunThatChargedNothingCannotBeDisputed() {
        var c = disputes.chargedRun("0.00");

        var response = open(c, c.buyerAdmin());

        assertThat(response.getStatusCode()).isEqualTo(HttpStatus.CONFLICT);
        assertThat(response.getBody().get("code")).isEqualTo("NOT_DISPUTABLE");
    }

    @Test
    void theWindowClosesAfterFourteenDays() {
        var c = disputes.chargedRun("284.00");
        Run run = runRepository.findById(c.run().getId()).orElseThrow();
        run.setCompletedAt(Instant.now().minus(Duration.ofDays(15)));
        runRepository.save(run);

        var response = open(c, c.buyerAdmin());

        assertThat(response.getStatusCode()).isEqualTo(HttpStatus.CONFLICT);
        assertThat(response.getBody().get("code")).isEqualTo("DISPUTE_WINDOW_CLOSED");
    }

    @Test
    void anotherWorkspaceCannotDisputeYourRun() {
        var c = disputes.chargedRun("284.00");
        OrgMembership stranger = identity.buyerAdmin("stranger-" + UUID.randomUUID() + "@acme.example");

        assertThat(open(c, stranger).getStatusCode()).isEqualTo(HttpStatus.NOT_FOUND);
    }

    @Test
    void approversCannotOpenDisputes() {
        var c = disputes.chargedRun("284.00");
        OrgMembership approver = identity.member(c.scenario().buyer(), "appr-" + UUID.randomUUID() + "@acme.example",
                UserRole.BUYER_APPROVER, null);

        assertThat(open(c, approver).getStatusCode()).isEqualTo(HttpStatus.FORBIDDEN);
    }

    @Test
    void theDeveloperAddsTheirSideAndTheDisputeMovesToAwaitingDecision() {
        var c = disputes.chargedRun("284.00");
        String id = (String) open(c, c.buyerAdmin()).getBody().get("id");

        var reply = rest.exchange(url("/api/v1/disputes/" + id + "/messages"), HttpMethod.POST,
                new HttpEntity<>(Map.of("body", "The statement had duplicate UTRs"), bearer(c.developer())), Map.class);

        assertThat(reply.getStatusCode()).isEqualTo(HttpStatus.OK);
        assertThat(reply.getBody().get("status")).isEqualTo("AWAITING_DECISION");
        var devList = rest.exchange(url("/api/v1/developer/disputes"), HttpMethod.GET,
                new HttpEntity<>(bearer(c.developer())), Map[].class).getBody();
        assertThat(devList).anySatisfy(d -> {
            assertThat(d.get("id")).isEqualTo(id);
            assertThat(d.get("buyerOrgName")).isEqualTo(c.scenario().buyer().getName());
        });
    }

    @Test
    void anotherDeveloperCannotReplyOrSeeIt() {
        var c = disputes.chargedRun("284.00");
        String id = (String) open(c, c.buyerAdmin()).getBody().get("id");
        var other = disputes.chargedRun("10.00").developer();   // a different developer org

        var reply = rest.exchange(url("/api/v1/disputes/" + id + "/messages"), HttpMethod.POST,
                new HttpEntity<>(Map.of("body", "not mine"), bearer(other)), Map.class);
        var list = rest.exchange(url("/api/v1/developer/disputes"), HttpMethod.GET, new HttpEntity<>(bearer(other)),
                Map[].class).getBody();

        assertThat(reply.getStatusCode()).isEqualTo(HttpStatus.NOT_FOUND);
        assertThat(list).noneMatch(d -> id.equals(d.get("id")));
    }

    @Test
    void withdrawingReleasesTheHold() {
        var c = disputes.chargedRun("284.00");
        String id = (String) open(c, c.buyerAdmin()).getBody().get("id");

        var withdrawn = rest.exchange(url("/api/v1/disputes/" + id + "/withdraw"), HttpMethod.POST,
                new HttpEntity<>(bearer(c.buyerAdmin())), Map.class);

        assertThat(withdrawn.getBody().get("status")).isEqualTo("WITHDRAWN");
        assertThat(disputeService.heldForDeveloper(c.developer().getOrg().getId())).isEqualByComparingTo("0");
    }
}
```

```sql
CREATE TABLE dispute (
    id                UUID          PRIMARY KEY,
    run_id            UUID          NOT NULL UNIQUE REFERENCES run(id),     -- one dispute per run, ever
    buyer_org_id      UUID          NOT NULL REFERENCES org(id),
    developer_org_id  UUID          NOT NULL REFERENCES org(id),
    agent_id          UUID          NOT NULL REFERENCES agent(id),
    agent_version_id  UUID          NOT NULL REFERENCES agent_version(id),
    status            VARCHAR(20)   NOT NULL,
    reason            VARCHAR(40)   NOT NULL,
    details           TEXT          NOT NULL,
    amount_disputed   NUMERIC(12,2) NOT NULL CHECK (amount_disputed > 0),
    amount_held       NUMERIC(12,2) NOT NULL CHECK (amount_held >= 0),
    amount_refunded   NUMERIC(12,2) CHECK (amount_refunded >= 0),
    public_summary    VARCHAR(280),
    opened_by_user_id UUID          NOT NULL,
    respond_by        TIMESTAMPTZ   NOT NULL,
    decide_by         TIMESTAMPTZ   NOT NULL,
    decided_by        UUID,
    decided_at        TIMESTAMPTZ,
    created_at        TIMESTAMPTZ   NOT NULL DEFAULT now(),
    CHECK (amount_refunded IS NULL OR amount_refunded <= amount_disputed)
);
CREATE INDEX dispute_developer_idx ON dispute (developer_org_id, status);
CREATE INDEX dispute_buyer_idx ON dispute (buyer_org_id, created_at DESC);
CREATE INDEX dispute_agent_decided_idx ON dispute (agent_id, decided_at DESC);

CREATE TABLE dispute_message (
    id             UUID        PRIMARY KEY,
    dispute_id     UUID        NOT NULL REFERENCES dispute(id),
    author_side    VARCHAR(10) NOT NULL,     -- BUYER, DEVELOPER
    author_user_id UUID        NOT NULL,
    body           TEXT        NOT NULL,
    created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX dispute_message_dispute_idx ON dispute_message (dispute_id, created_at);
```

```java
@Service
public class DisputeService {

    public enum Side { BUYER, DEVELOPER }

    static final Set<DisputeStatus> OPEN_STATUSES = EnumSet.of(DisputeStatus.OPEN, DisputeStatus.AWAITING_DECISION);

    private final DisputeRepository disputeRepository;
    private final DisputeMessageRepository messageRepository;
    private final RunRepository runRepository;
    private final OrgRepository orgRepository;
    private final UserRepository userRepository;
    private final AgentRepository agentRepository;
    private final DomainEventPublisher eventPublisher;
    private final Duration window;
    private final Duration respondWithin;
    private final Duration decideWithin;

    public DisputeService(DisputeRepository disputeRepository, DisputeMessageRepository messageRepository,
                          RunRepository runRepository, OrgRepository orgRepository, UserRepository userRepository,
                          AgentRepository agentRepository, DomainEventPublisher eventPublisher,
                          @Value("${agentstore.disputes.window:P14D}") Duration window,
                          @Value("${agentstore.disputes.respond-within:P7D}") Duration respondWithin,
                          @Value("${agentstore.disputes.decide-within:P14D}") Duration decideWithin) {
        this.disputeRepository = disputeRepository;
        this.messageRepository = messageRepository;
        this.runRepository = runRepository;
        this.orgRepository = orgRepository;
        this.userRepository = userRepository;
        this.agentRepository = agentRepository;
        this.eventPublisher = eventPublisher;
        this.window = window;
        this.respondWithin = respondWithin;
        this.decideWithin = decideWithin;
    }

    @Transactional
    public Dispute open(UUID runId, UUID buyerOrgId, UUID userId, DisputeReason reason, String details) {
        Run run = runRepository.findByIdForUpdate(runId)
                .filter(r -> r.getConnection().getBuyerOrg().getId().equals(buyerOrgId))
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "Run not found"));
        if (!run.getStatus().isTerminal() || run.getTotalCharged() == null || run.getTotalCharged().signum() <= 0) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "NOT_DISPUTABLE",
                    "Only finished runs that charged something can be disputed");
        }
        Instant now = Instant.now();
        if (run.getCompletedAt() == null || run.getCompletedAt().plus(window).isBefore(now)) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "DISPUTE_WINDOW_CLOSED",
                    "Runs can be disputed within " + window.toDays() + " days of finishing");
        }
        if (disputeRepository.existsByRunId(runId)) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "ALREADY_DISPUTED", "This run was already disputed");
        }

        Dispute d = new Dispute();
        d.setRunId(runId);
        d.setBuyerOrgId(buyerOrgId);
        d.setDeveloperOrgId(run.getConnection().getAgent().getDeveloperOrg().getId());
        d.setAgentId(run.getConnection().getAgent().getId());
        d.setAgentVersionId(run.getAgentVersion().getId());
        d.setStatus(DisputeStatus.OPEN);
        d.setReason(reason);
        d.setDetails(details.trim());
        d.setAmountDisputed(run.getTotalCharged());
        d.setAmountHeld(run.getTotalCharged());
        d.setOpenedByUserId(userId);
        d.setCreatedAt(now);
        d.setRespondBy(now.plus(respondWithin));
        d.setDecideBy(now.plus(decideWithin));
        d = disputeRepository.save(d);

        eventPublisher.publish(DomainEventType.DISPUTE_OPENED, buyerOrgId, "DISPUTE", d.getId(), userId, Map.of(
                "agentName", run.getConnection().getAgent().getName(), "runId", runId.toString(),
                "amount", d.getAmountDisputed().toPlainString()));
        return d;
    }

    @Transactional
    public Dispute addMessage(UUID disputeId, Side side, UUID orgId, UUID userId, String body) {
        Dispute d = lockedFor(disputeId, side, orgId);
        if (!d.getStatus().isOpen()) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "ALREADY_DECIDED", "This dispute is closed");
        }
        messageRepository.save(new DisputeMessage(disputeId, side.name(), userId, body.trim()));
        if (side == Side.DEVELOPER && d.getStatus() == DisputeStatus.OPEN) {
            d.setStatus(DisputeStatus.AWAITING_DECISION);
            disputeRepository.save(d);
        }
        return d;
    }

    @Transactional
    public Dispute withdraw(UUID disputeId, UUID buyerOrgId, UUID userId) {
        Dispute d = lockedFor(disputeId, Side.BUYER, buyerOrgId);
        if (!d.getStatus().isOpen()) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "ALREADY_DECIDED", "This dispute is closed");
        }
        d.setStatus(DisputeStatus.WITHDRAWN);
        d.setAmountHeld(BigDecimal.ZERO);
        d.setDecidedAt(Instant.now());
        d.setDecidedBy(userId);
        return disputeRepository.save(d);
    }

    /** Earnings held back from a developer's next payout. WS10's earnings and payout batch read this. */
    public BigDecimal heldForDeveloper(UUID developerOrgId) {
        return disputeRepository.sumHeld(developerOrgId, OPEN_STATUSES);
    }

    /** 404 (not 403) for anyone who is not a party, so dispute ids reveal nothing. */
    Dispute lockedFor(UUID disputeId, Side side, UUID orgId) {
        Dispute d = disputeRepository.findByIdForUpdate(disputeId)
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "Dispute not found"));
        UUID party = side == Side.BUYER ? d.getBuyerOrgId() : d.getDeveloperOrgId();
        if (!party.equals(orgId)) throw new ResponseStatusException(HttpStatus.NOT_FOUND, "Dispute not found");
        return d;
    }

    public DisputeView view(Dispute d, boolean includeBuyerName) {
        var messages = messageRepository.findByDisputeIdOrderByCreatedAtAsc(d.getId()).stream()
                .map(m -> new DisputeView.Message(m.getAuthorSide(),
                        userRepository.findById(m.getAuthorUserId()).map(User::getFullName).orElse(null),
                        m.getBody(), m.getCreatedAt()))
                .toList();
        String agentName = agentRepository.findById(d.getAgentId()).map(a -> a.getName()).orElse(null);
        String buyerName = includeBuyerName
                ? orgRepository.findById(d.getBuyerOrgId()).map(o -> o.getName()).orElse(null) : null;
        return new DisputeView(d.getId(), d.getRunId(), d.getAgentId(), agentName, buyerName, d.getStatus(),
                d.getReason(), d.getDetails(), d.getAmountDisputed(), d.getAmountHeld(), d.getAmountRefunded(),
                d.getPublicSummary(), d.getRespondBy(), d.getDecideBy(), d.getCreatedAt(), d.getDecidedAt(), messages);
    }
}
```

```java
    @Transactional
    public LedgerEntry refundForDispute(UUID disputeId, UUID runId, UUID buyerOrgId, java.math.BigDecimal amount) {
        var existing = ledgerEntryRepository.findByDisputeId(disputeId);
        if (existing.isPresent()) {

        wallet.setUpdatedAt(Instant.now());
        walletRepository.save(wallet);
        return entry;
```

```java
    @Transactional
    public Dispute decide(UUID disputeId, UUID adminUserId, boolean refund, BigDecimal amountRefunded,
                          String publicSummary) {
        if (publicSummary == null || publicSummary.isBlank() || publicSummary.trim().length() > 280) {
            throw new ResponseStatusException(HttpStatus.BAD_REQUEST, "A public summary of 1 to 280 characters is required");
        }
        Dispute d = disputeRepository.findByIdForUpdate(disputeId)
                .orElseThrow(() -> new ResponseStatusException(HttpStatus.NOT_FOUND, "Dispute not found"));
        if (!d.getStatus().isOpen()) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "ALREADY_DECIDED", "This dispute was already decided");
        }
        if (d.getStatus() == DisputeStatus.OPEN) {
            throw new ApiProblemException(HttpStatus.CONFLICT, "WAITING_FOR_DEVELOPER",
                    "The developer can add their side until " + d.getRespondBy());
        }
        BigDecimal refunded = BigDecimal.ZERO;
        if (refund) {
            if (amountRefunded == null || amountRefunded.signum() <= 0
                    || amountRefunded.compareTo(d.getAmountDisputed()) > 0) {
                throw new ApiProblemException(HttpStatus.BAD_REQUEST, "REFUND_OUT_OF_RANGE",
                        "A refund must be above ₹0 and at most ₹" + d.getAmountDisputed().toPlainString());
            }
            refunded = amountRefunded.setScale(2, java.math.RoundingMode.HALF_UP);
            ledgerService.refundForDispute(d.getId(), d.getRunId(), d.getBuyerOrgId(), refunded);
        }
        d.setStatus(refund ? DisputeStatus.REFUNDED : DisputeStatus.NOT_REFUNDED);
        d.setAmountRefunded(refunded);
        d.setAmountHeld(BigDecimal.ZERO);   // WS10 settles the developer leg from amountRefunded
        d.setPublicSummary(publicSummary.trim());
        d.setDecidedBy(adminUserId);
        d.setDecidedAt(Instant.now());
        d = disputeRepository.save(d);

        eventPublisher.publish(DomainEventType.DISPUTE_DECIDED, d.getBuyerOrgId(), "DISPUTE", d.getId(), adminUserId,
                Map.of("agentName", agentRepository.findById(d.getAgentId()).map(a -> a.getName()).orElse(""),
                        "outcome", d.getStatus().name(), "amountRefunded", refunded.toPlainString()));
        return d;
    }
```

```java
package com.agentstore.platform.disputes;

import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.time.Instant;

@Component
public class DisputeDeadlines {

    private final DisputeRepository disputeRepository;

    public DisputeDeadlines(DisputeRepository disputeRepository) {
        this.disputeRepository = disputeRepository;
    }

    @Transactional
    public int advanceAt(Instant now) {
        int moved = 0;
        for (Dispute candidate : disputeRepository.findByStatusAndRespondByBefore(DisputeStatus.OPEN, now)) {
            Dispute d = disputeRepository.findByIdForUpdate(candidate.getId()).orElse(null);
            if (d != null && d.getStatus() == DisputeStatus.OPEN) {
                d.setStatus(DisputeStatus.AWAITING_DECISION);
                disputeRepository.save(d);
                moved++;
            }
        }
        return moved;
    }
}
```

```java
package com.agentstore.platform.disputes;

import net.javacrumbs.shedlock.spring.annotation.SchedulerLock;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

@Component
@ConditionalOnProperty(name = "agentstore.jobs.enabled", havingValue = "true", matchIfMissing = true)
public class DisputeDeadlineJob {

    private final DisputeDeadlines deadlines;

    public DisputeDeadlineJob(DisputeDeadlines deadlines) {
        this.deadlines = deadlines;
    }

    @Scheduled(fixedDelayString = "PT10M")
    @SchedulerLock(name = "disputeDeadlines", lockAtMostFor = "PT5M", lockAtLeastFor = "PT10S")
    public void run() {
        // Called through the Spring bean so @Transactional applies and each row lock is held until commit.
        deadlines.advanceAt(java.time.Instant.now());
    }
}
```
